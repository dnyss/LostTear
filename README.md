## Tecnologías

* **Language:** C#
* **Game Engine:** Unity.

## Probar la aplicación

Dentro del repositorio:

```bash
1. Buscar carpeta builds
2. Descargar carpeta LostTearDemo 
3. Ejecutar LostTearDemo.exe
```


## Correr el proyecto

* Clonar repositorio:

```bash
git clone https://github.com/dnyss/LostTear.git
```

* Abrir carpeta Lost Tear en Unity. Editor version: 6000.0.33f1

* Correr proyecto en Unity

## Estructura del proyecto

```text
Lost Tear/
├── Assets/
│   ├── Dialogue System/
│   ├── Scenes/
│   ├─────── Animations/
│   ├─────── Art/
│   ├─────── CutscenesINTRO/
│   ├─────── Dialogos/
│   ├─────── Prefabs/
│   ├─────── ...
│   └── ...
├── Builds/
├── Packages/
├── ProjectSettings/
├── .gitignore
├── README.md
```

Directorios importantes:

| Directorio | Descripción |
| ---------- | ---------- |
| Dialogue System | Scriptable objects utilizados en sistema de dialogo. |
| Prefabs | Contiene prefabs que se reutilizan en el juego, plataformas, elementos interactuables. |
| Scenes | Escenas del proyecto. |
| Scripts | Archivos de código. |
